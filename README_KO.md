# ToneMatch TMP 0.1.05

권한 있는 로컬 오디오·영상 또는 Windows 녹음을 분석하는 비공식 Windows 도구입니다.
전체 음원 코드표와 Fender Tone Master Pro 또는 Quad Cortex용 시작점 톤 레시피 3개를 제공합니다.
소스 기준일: 2026-10-17 KST. 서명되지 않은 CPU 개발자 프리릴리스입니다.
2026-10-18 소스·실행파일·독립 ZIP 검증 후 게시했습니다: [v0.1.05 다운로드](https://github.com/JH-Prime/ToneMatchTMP/releases/tag/v0.1.05).
공개 자산 3개의 크기·해시 일치도 확인했습니다. 새 폴더에 압축을 풀고 음원을 다시 분석하세요.
최종 검증 범위는 [v0.1.05 QA 보고서](QA_REPORT_v0.1.05.json)와 [빌드 이력](BUILD_HISTORY.md)에 기록합니다.

## 0.1.05 변경 사항

- 코드를 확정하지 못한 구간도 관측한 음과 최대 3개 후보를 아래에 표시합니다.
  본문은 계속 `?`로 남으며 후보를 확정 코드처럼 표시하거나 앞뒤 코드로 채우지 않습니다.
- 낮은 음량, 부족한 음정 근거, 비슷하거나 약한 후보, 짧은 시간 지지, 미관측 공백,
  출력 제한을 구별합니다. `?`는 코드가 없다는 뜻도, 음악 기호 `N.C.`도 아닙니다.
- CQT는 후보가 있는 일부 미확정 관측에 한해 0.3초·1.0초 길이로 다시 확인합니다.
  화성 변화 경계 안에서 기존 CQT 결과를 재사용하며 두 길이의 코드 일치, 원래 관측음,
  충분한 근거와 시간 지지를 요구합니다. 반복해서 답을 만들거나 무음을 코드로 채우지 않습니다.
- FFT에도 후보·미확정 사유 보존을 적용하지만 위의 새 재검토는 **CQT 전용**입니다.
  CQT 결과는 최대 4096개 이벤트로 제한하며 한도로 생략된 부분은 출력 제한으로 표시합니다.
- 화면·HTML·PDF·JSON 재열기에서 후보와 사유를 유지합니다. 직접 수정한 코드는 자동
  추정 근거와 구별하며 원본 복원 시 이전 후보를 다시 볼 수 있습니다. 기타 운지는 추가하지 않습니다.

후보 표시나 검출 비율 증가가 정답률 향상을 뜻하지 않습니다. 모든 누락 코드를 복구하거나
실제 곡의 채보 정확도를 보장하지 않으며, 기존 결과와 보관한 v0.1.04 폴더는 유지하세요.

확인된 소스 검증: 창 생성을 차단한 테스트 348개 통과, 실제 GUI 테스트 92개 보류입니다.
CQT/FFT 합성 비교 32개 사례를 통과했고, 새로 채택된 정답·오답 구간은 모두 0초였습니다.
11개 합성 코드 추적 사례의 시간 가중 기호 일치율은 이전 버전과 같은 99.36%로,
실제 곡 정답률이 아닙니다. 로컬 Room 335 CQT 검사(252.61초)는 검출 비율 49.51%를
유지하면서 미확정 후보 근거 2.25초를 보존했고, 재검토로 복구된 관측은 0개였습니다.
같은 전체 파일의 FFT 검사도 통과했으며 검출 비율 35.87%를 유지하고 미확정 후보 근거
113.10초를 보존했습니다. 후보가 더 많이 나오는 것이 더 정확하다는 뜻은 아닙니다.
실행파일의 CQT/FFT·미확정 근거 재열기/내보내기·PDF 글꼴·믹서 저장·C++ ABI 2 검증을 통과했습니다.
게시 전에는 ZIP을 새로 풀어 검증하고 공개 자산 해시까지 대조하며, 결과는 별도 압축 검증 보고서에 남깁니다.

아래 v0.1.04 이하 항목의 수치·검증 기록은 해당 과거 버전에 대한 기록입니다.

## 0.1.04 변경 사항

- 분석 완료·실패·취소 후 멀티이펙터 선택이 잠긴 채 남는 문제를 수정했습니다.
- `코드만 분석` 대기 상태에서도 다음 톤 분석용 장비를 고를 수 있습니다.
  코드 분석 자체는 선택 장비와 무관하며, 실제 작업 중에는 선택 잠금을 유지합니다.
- CQT 관측 간격을 50ms로 좁히고 화성 변화 경계를 이용해 서로 다른 코드의 증거가
  섞이는 현상을 줄였습니다. 곡 시작·끝의 짧은 코드와 분수코드를 보존합니다.
  **50ms는 관측 간격이지 정확도 보장이 아닙니다.** 오디오 샘플레이트를 인위적으로 늘리지 않습니다.
- 11개 정답 주석 합성 신호의 시간 가중 코드 일치율은 90.66% → 99.36%였습니다.
  개발용 시험 신호 결과이며 실제 곡 정답률은 아닙니다. 세밀한 분석은 계산량을 늘립니다.
  동일 결과를 보존하는 경로·템플릿 최적화로 부담을 줄였지만 전체 분석 속도 향상을 보장하지 않습니다.
- 화면 조작 없이 상태 회귀·분석·저장 경로를 검증했습니다. 이번 패치의 실제 클릭·시각 검사는 보류했습니다.
  CQT/FFT 선택과 기존 저장 결과·수동 수정은 유지합니다.

## 0.1.03 변경 사항

- 입력 상단에서 `톤 + 코드` 또는 `코드만 분석`을 넓은 선택 버튼으로 고릅니다.
- `코드 분석 방식`에서 **CQT(기본)** 또는 **FFT(기존 방식)**를 선택합니다.
  둘 다 선택한 원본 전체 음원을 분석하며, 기타 운지는 표시하지 않습니다.
  FFT는 기존 고정 440 Hz·음역 가중치·배음 억제 경로이고 CQT의 튜닝 보정을 공유하지 않습니다.
- 장비 목록을 열어보는 버튼을 없앴습니다. 내부 추천 모델 데이터는 유지합니다.
- 재생·선택 마디 반복·악보 따라가기의 어두운 스타일, 작은 창 배치와 한·영 글꼴을 수정했습니다.
  GUI는 한글 맑은 고딕, English Arial Narrow를 요청합니다. PDF는 재배포 가능한 나눔고딕을 유지합니다.
- 분석 방식은 JSON 재열기·언어 변경·HTML·PDF에서도 유지됩니다. FFT 결과도 즉시 직접 수정할 수 있습니다.
- 두 방식의 근거·후보를 비교해 사용하세요. **FFT나 CQT가 모든 곡에서 더 정확하다고 검증되지는 않았습니다.**

문제가 있으면 보관한 v0.1.02 폴더로 돌아가세요. 기존 릴리스와 사용자 음원은 변경하지 않습니다.

## 0.1.02 추가 사항

- **코드만 분석**을 켜면 기타 분리·AI 다운로드·멀티이펙터 선택 없이 전체 음원을 분석합니다.
- Quad Cortex와 장비의 CorOS를 선택하면 6개 내장 모델 시작점 중 3개를 추천합니다.
  장비 기본값에서 시작하세요. 미검증 노브 수치를 만들거나 TMP 수치를 옮기지 않습니다.
  구형 펌웨어는 목록의 이전 이름을 사용할 수 있으며, 없는 선택적 딜레이는 이유와 함께 제외합니다.
- 내부 QC 추천은 2026-10-07 [공식 목록](https://neuraldsp.com/device-list)을 참고합니다.
  목록 열람 UI는 0.1.03에서 제거했고, 라이선스 필요·미출시 항목은 기본 추천에서 제외됩니다.
- CQT는 앞·중간·끝 최대 12초의 피크 합의로 전체 튜닝 편차를 보정하고 근거가 약하면 0으로 유지합니다.
  ±30/45센트 합성 C·Am·Dsus4 12개 사례는 통과했지만 곡 중간 튜닝 변화는 추적하지 않습니다.
- Room 335의 코드 검출 비율은 전체 11.88%, 30–90초 구간 23.23%로 이전과 같습니다.
  **이는 정확도가 아닙니다.** 실제 곡 정답률 상승은 검증하지 못했습니다.
- QC·코드 전용 결과의 JSON 재열기·언어 변경·HTML 내보내기를 지원합니다.

문제가 생기면 보관한 v0.1.01 폴더로 돌아갈 수 있습니다. 새 결과 형식은 구버전에서 열리지
않을 수 있으므로 이전 결과 원본을 보존하고 새 이름으로 저장하세요.

## 이번 버전

- 기타 분리음 대신 **원본 전체 음원**을 CQT → chroma → 41종 화음 템플릿으로 분석합니다.
  slash·sus·확장 코드를 유지하고 코드명 아래 근거와 다른 후보를 표시합니다.
  자동 기타 운지·현·프렛 그림은 코드 결과에서 제거했습니다.
- 음원을 재생·일시 정지·탐색하고 코드표의 현재 위치와 페이지를 따라갑니다.
  반복 구간과 코드 클릭 탐색을 지원하며 자동으로 소리를 재생하지 않습니다.
- 코드를 직접 수정하고 실행 취소·원본 복원·결과 JSON 재열기를 지원합니다.
- 6개 악기의 음량·Mute·Solo·원본 비교와 개별/믹스 WAV 저장을 지원합니다.
- 16마디 A4 PDF를 저장하고, 원할 때 PDF 뷰어를 열어 인쇄할 수 있습니다.

**CQT 도입이 실제 곡의 정답률 향상을 보장하지 않습니다.** C6/Am7처럼 같은 음 집합의
이름이 문맥에 따라 달라질 수 있고 빠른 변화·멜로디·배음·타악기·생략음 때문에
오답이나 `?`가 나옵니다. 근거 점수는 정확도 확률이 아닙니다.
기타 톤 분석·Reference는 기존 분리 기타 경로를 유지합니다.

## 설치와 분석

1. 개발자 ZIP을 새 폴더에 **전부 압축 해제**하고 SHA-256을 확인합니다.
   검증·게시된 패키지의 `ToneMatchTMP-v0.1.05.exe`를 실행합니다. EXE만 옮기지 마세요.
2. `톤 분석`에서 로컬 오디오/영상 또는 권한 있는 PC 재생음 녹음을 선택합니다.
3. 시작/끝 초를 정합니다. 최소 3초, 최대 20분이며 끝 `0`은 파일 끝까지입니다.
4. 풀믹스는 AI 기타 분리, 이미 기타만 있는 파일은 분리 생략을 선택합니다.
   내 기타 픽업·멀티이펙터 출력 연결·연산 장치를 지정하고 분석합니다.
5. 진행률과 경과 시간을 보며 기다립니다. 취소는 현재 추론 블록이 끝날 때까지 지연될 수 있습니다.

첫 AI 분리에는 인터넷과 모델 저장 공간이 필요합니다. 완성된 사용자 모델 캐시는 재사용합니다.
모델 가중치는 ZIP에 없습니다. CPU 포터블은 CUDA를 포함하지 않으며 긴 곡의 분리는 느릴 수 있습니다.
분리 없는 코드 계산 자체는 모델 다운로드를 하지 않지만, 현재 톤 분석 작업에서 기타 분리가
실패하면 전체 톤 분석이 중단될 수 있습니다. 이때 `코드만 분석`으로 기타 분리 없이 실행할 수 있습니다.

## 코드표 · 재생 · 수정

결과의 `코드·보이싱` 탭에서 한 줄 4마디·한 페이지 16마디를 봅니다.
운지 대신 코드명, 미확정 구간, 구성음 근거와 후보를 확인하세요.
마디 설정의 BPM·한 마디 박 수·첫 마디 위치를 음원에 맞게 조절합니다.
첫 마디 위치는 **분석 구간 시작 기준 상대 초**입니다. 원본 30초부터 분석할 때
첫 마디 `2`는 원본 32초입니다. 수동 일정 템포 격자이며 자동 강박·변박 추적이 아닙니다.

재생 준비 후 재생을 직접 누릅니다. 코드 선택으로 해당 위치를 탐색하고 반복 구간을 정할 수 있습니다.
장치 처리 버퍼 때문에 표시 위치와 실제 들리는 소리에 약간의 지연 차이가 있을 수 있습니다.
기본 출력 장치를 사용하며 ASIO·독점 모드는 아닙니다.

코드 편집에서 기호(예: `Dm9`, `C/E`, `Gsus4`, `?`)를 적용합니다.
수정은 원본 추정과 별도로 저장하며 새 코드에 자동 근거 점수를 붙이지 않습니다.
최대 50단계 실행 취소와 원본 복원을 지원합니다. JSON에는 수정·마디 설정이 포함되고,
재열기 시 파일 경로를 자동 신뢰하거나 소리를 재생하지 않습니다. 재생하려면 원본을 다시 연결하세요.
HTML·PDF는 적용된 수정 결과를 사용합니다.

## 악기 믹서와 WAV

`악기 제거` 화면에서 믹서를 열고 파일·구간을 준비합니다.
vocals / drums / bass / guitar / piano / other의 6개 추정음을 한 번 분리합니다.
각 음량 0–200%, Mute, Solo를 바꿔도 다시 AI 분리를 실행하지 않습니다.
여러 Solo는 함께 들리고 Mute가 Solo보다 우선합니다.
원본 비교는 모니터링 전용이며 믹스 저장에는 fader/Mute/Solo 설정이 적용됩니다.

개별 WAV는 그 악기의 원래 상대 레벨을 사용하므로 fader/Mute/Solo를 반영하지 않습니다.
개별·믹스 모두 공통 클리핑 방지 계수를 사용해 원본보다 작게 들릴 수 있습니다.
새 44.1 kHz stereo PCM16 WAV만 저장하며 원본·기존 출력은 덮어쓰지 않습니다.
분리음은 작업 동안 임시 디스크에 보관되고 앱 종료 시 정리됩니다. 20분 스테레오 6개 분리음은
원본 PCM을 제외해도 약 2.54 GB의 임시 공간이 필요합니다.

기존 악기 제거 기능도 유지합니다. **새 분리 모델이나 품질 향상은 검증되지 않았습니다.**
guitar·piano는 추정이며 piano가 모든 건반을 뜻하지 않습니다. 누출·빠진 음·인공음이 있을 수 있습니다.
Logic Pro와 동일 품질을 보장하지 않습니다. 내보낸 음원의 사용·공유 권한은 직접 확인하세요.

## PDF와 인쇄

도구 메뉴에서 16마디 PDF 저장을 선택합니다. A4 한 페이지에 4×4 코드표를 넣고,
근거와 모든 변화는 아래 상세 목록/이어지는 상세 페이지에 남깁니다.
빽빽한 마디는 대표 기호 3개와 추가 표시를 쓰며 상세 목록에서 나머지를 확인합니다.
한글 Nanum Gothic을 포함하므로 폰트 설치가 필요하지 않습니다.
`PDF 저장 후 인쇄 보기`는 저장 성공 후 기본 뷰어만 엽니다.
**인쇄 명령은 자동 전송하지 않으며** 뷰어에서 용지·배율·프린터를 확인해 인쇄합니다.

## 기존 기능과 경계

한국어/English, 실시간 입력 스펙트럼, 레벨 정규화 Reference Compare, 녹음,
별도 코드·스케일 사전(41화음·12음계·장조/자연단조 다이어토닉), 개발자 소스 보기를 유지합니다.

실시간 PCM·FFT·평활화는 C++ ABI 2이며 불가 시 NumPy로 대체합니다.
CQT·AI·UI·오디오 장치 제어를 전부 C++로 전환한 것은 아닙니다.

톤 추천은 펌웨어 1.8.58 / Model Guide Rev. J 카탈로그에 기반한 수동 입력용 시작점입니다.
기기 프리셋 자동 전송·Fender DSP 복제·정확한 원곡 장비 식별은 하지 않습니다.
JSON은 Tone Master Pro의 `.preset` 파일이 아닙니다.
YouTube URL 입력·자동 추출은 제공하지 않습니다. 권한 있게 확보한 로컬 파일을 사용하세요.
실제 곡 정답률·청감·물리 캡처·프린터·새 PC·첫 다운로드·오프라인·CUDA 검증과 코드 서명 여부는
QA의 미검증 항목을 확인하세요. 합성 테스트 통과는 이런 검증을 대신하지 않습니다.

## 개발 재개와 빌드

Windows x64 Python 3.12를 사용합니다. ZIP의 `source`가 자체 완결된 소스 폴더입니다.
Git clone은 큰 FFmpeg/DLL 바이너리를 포함하지 않습니다. FFmpeg는 개발자 ZIP의
`source/resources/ffmpeg.exe`를 복사하고 DLL은 아래 명령으로 빌드합니다.

```powershell
py -3.12 -m venv ..\.venv
& ..\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
& ..\.venv\Scripts\python.exe tools\build_native.py --zig C:\Tools\zig-0.15.2\zig.exe
& ..\.venv\Scripts\python.exe -W error tools\verify_headless.py --output .\headless-v0.1.05.json
& ..\.venv\Scripts\python.exe app.py --self-test-output .\self-test-v0.1.05.json
& .\build.ps1 -SkipTests -ZigPath C:\Tools\zig-0.15.2\zig.exe
```

위 순서는 화면을 열지 않는 회귀 검증이 통과한 뒤 빌드에서 테스트 재실행만 생략합니다.
`verify_headless.py`는 Tk 창 생성을 금지하고 GUI 포함 테스트를 보류 목록에 기록합니다.
전체 unittest discovery와 `-SkipTests` 없는 빌드는 창을 만드는 테스트를 포함하므로
화면 조작이 허용된 별도 검증에서만 실행하세요. 보류한 GUI 검증을 완료로 간주하지 않습니다.

`3a0ed1e8799a2f8ce2a6e6290a9ff22e6906f8227865911fb7ddedc3cc14cb0c`.
일반 EXE 사용에는 컴파일러가 필요하지 않습니다.
CUDA 소스 개발은 `enable_cuda.ps1`와 별도 호환 GPU 환경을 사용하고 재검증합니다.
자체 진단은 CQT·수정·믹서 PCM/WAV·PDF/글꼴·PortAudio DLL과 기존 C++ 수치를 검사하되
