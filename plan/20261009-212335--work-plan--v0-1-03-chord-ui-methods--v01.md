## Selectable chord analysis and data contracts

Reuse the existing FFT detector rather than introducing a new algorithm bearing the same name. Both selectable methods must take the same decoded original full mixture and the same selected time interval, whether tone extraction also runs or not. Neither method may silently analyze a separated guitar stem in this workflow. Preserve the user's decision to display chord symbols with evidence and alternatives, not automatic guitar fingering or separated-note diagrams. Normalize legacy FFT results at the narrow integration boundary to remove automatic shapes and guitar-only context from the whole-song presentation.

The old FFT detector needs an operational review before exposing it to full-length user jobs. Preserve maximum duration and memory bounds, cancellation between meaningful units, monotonic progress, finite-input validation, antiphase-channel handling and complete chronological coverage. Avoid wrapping a non-cancellable twenty-minute operation behind a progress animation. Add optional progress and cancellation support in the existing implementation if its window loop is the smallest correct seam. Keep its existing public defaults working for legacy tests and internal diagnostics. Do not weaken chord acceptance thresholds to create apparently denser results.

Keep a stable, validated method identity in results and diagnostics. Save/reopen, localization, HTML, chart details and relevant PDF context must not relabel FFT as CQT. Preserve compatibility for old saved files without the new explicit field by deriving only what the existing method evidence supports; use a neutral legacy/unknown label when the evidence is insufficient. Reject malformed new method values before decoding or starting AI work. Preserve manual edits, undo, chart timing overrides and evidence metadata independently of the method choice. A manually corrected symbol remains a correction, not new algorithm evidence.

Do not invent physical certainty for identical pitch-class sets such as C6 and Am7. Retain alternatives, unknown spans and truthful score semantics. Analyze deterministic extended, slash and suspended chords, detuned signals, silence, noise and antiphase stereo. CQT tuning correction stays in its existing bounded path; expose genuine differences from the legacy FFT method rather than secretly turning both menu options into the same implementation. Do not add heavy models or native dependencies solely to obtain a marketing accuracy claim.
