# v0.1.13 source review

Baseline `bdaa864b505da49abc4768c9d04faa4fbf62c4ea` on local and remote main. The release baseline is v0.1.12.

## Findings reproduced and addressed

- **Recording could destroy another WAV.** The app reused second-resolution names and the recorder used a truncating open. A fixture held an existing destination and disconnected a fake input device. The old path deleted the destination. The recorder now claims a path exclusively. The app uses unique names and adds only successful recordings to its cleanup list. See [recorder.py](../../recorder.py) and [capture tests](../../tests/test_recorder.py).
- **Analysis could relinquish ownership before the terminal event.** A completed fake worker with an unread result allowed availability checks to treat the application as idle. The queued result could then update the UI during a later operation. The app keeps ownership until the main loop handles the event. Closing now waits for active capture, monitoring and analysis to finish with their files and streams. See [device lifecycle tests](../../tests/test_device_lifecycle.py).
- **Malformed settings could prevent startup.** A surviving `settings.json` containing a JSON list, null, or an array for language bypassed parsing checks and raised before the UI loaded. The loader preserves defaults for invalid fields and keeps valid selections. See [device lifecycle tests](../../tests/test_device_lifecycle.py).
- **Guitar separation could accept shortened or non-finite output.** A fake model returned half the requested frames or a same-size NaN tensor. Both completed on the prior output path. The guitar-only path now uses the shared stereo validator and checks the returned frame count before writing PCM. See [separator tests](../../tests/test_separator.py).
- **Stereo cancellation and quiet reference requirements blocked tone analysis.** Equal opposite-polarity synthetic channels cancelled when folded down. Analysis now uses the side signal when the mid signal falls below the silence threshold, and a below-threshold optional reference produces a localized warning while tone analysis continues. See [engine tests](../../tests/test_engine.py).
- **Reopening a result could discard measured data.** A saved tone result lost its spectral reference, clipping warning and separation diagnostics when reopened. The loader validates and restores reference measurements, raw features, separation diagnostics and the report schema, and older feature-only results retain their clipping warning. Legacy PDF export now uses the analysis source offset when the chord timeline does not carry one. See [result tests](../../tests/test_chord_edits.py) and [PDF tests](../../tests/test_chart_pdf.py).
- **A late practice export cancellation hid a finished save.** A fake export committed its output, then the user cancelled before the result poll. The previous UI reported cancellation despite the completed file. The result now distinguishes a completed export from obsolete playback and a cancelled export. See [practice tests](../../tests/test_practice_window.py).
- **A partially damaged activated update cache stayed unusable.** The updater verified newly downloaded files but repeatedly fell back when the activated installation was damaged. Recovery checks the downloaded release against the active pointer and replaces only expected damaged files. It verifies the complete installation before returning it. Unknown files and directories prevent recovery. See [updater tests](../../tests/test_auto_update.py).
- **The build generated an old application version in license inventory.** The prior ZIP carried a hard-coded v0.1.01 inventory heading. The generated heading now describes the application independently of the release version. See [inventory generator](../../tools/collect_licenses.py).

## Coverage and deferred verification

Reviewed the active application paths for input, tone recommendation, chord extraction and uncertainty, editing and result reopening, report and PDF export, reference comparison, playback, local practice, stem jobs and native DSP integration. Reviewed startup, the updater, runtime cache, archive and signing preparation and the reference and catalog display entry points. Followed the baseline through tracked source, synthetic and mocked tests, and release artifacts. The checks target current first-party code and cross-module behavior. Earlier commits, third-party implementation, every display layout and every attached device or hardware combination were outside this audit.

Parsed and compiled all 115 tracked Python and PyInstaller sources. Exercised 170 combinations of cadence key spelling, tonal mode and transposition against the chart parser and twelve-key order.

The guarded suite covers synthetic and fake-device contracts. Native Tk layout, fonts as rendered on screen, listening, GPU or sound-device performance on real hardware, real-song chord accuracy and live Store installation still require separate measurements. The room sample was kept out of the test and packaging path.
